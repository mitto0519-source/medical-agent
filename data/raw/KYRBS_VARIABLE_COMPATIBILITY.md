## 주요 한계점 상세

### 1. F_BR (아침식사) — 코딩 체계 2011년 변경 ⚠️

| 연도 | 최대값 | 코딩 체계 | 결식 기준 |
|------|--------|-----------|-----------|
| 2005~2010 | 4 | 1=매일, 2=주5-6일, 3=주3-4일, **4=결식** | F_BR == 4 |
| 2011~2025 | 8 | 1=7일, 2=6일, ..., 7=1일, **8=결식** | F_BR == 8 |

→ **Loader 처리**: `F_BR.max() <= 4` 이면 결식 기준 = `==4`, 아니면 `==8` (자동 감지)

### 2. 신체활동 — 변수명 2022년 변경

| 연도 | 변수명 | 설명 |
|------|--------|------|
| 2005~2021 | `PA_VIG` | 격렬 신체활동 일수(주) |
| 2022~2025 | `PA_VIG_D` | 격렬 신체활동 일수(주) — 동일 개념, 이름만 변경 |

→ **Loader 처리**: VAR_MAP에 양쪽 모두 포함, 자동 매핑

### 3. 스크린 타임 — 개념 자체가 변경 ⚠️⚠️

| 연도 | 변수명 | 개념 |
|------|--------|------|
| 2005~2006 | 없음 | 해당없음 |
| 2007~2010 | `INT_WD_MM` | 인터넷 이용시간(분/주중) — PC 인터넷 전체 |
| 2011~2019 | `INT_WD_MM` | 인터넷 이용시간(분/주중) — 스마트폰 포함 복합 |
| 2020~2025 | `INT_SPWD_TM` | **스마트폰** 이용시간(분/주중) — 특화 |

→ **분석 주의**: 2020 이전과 이후는 스크린 타임 비교 불가 (개념 다름)  
→ **Loader 처리**: 둘 다 `screen_time`으로 매핑하되 `meta["screen_time_concept"]`로 구분

### 4. 수면 — 2005~2006 변수 체계 다름

| 연도 | 변수 | 처리 |
|------|------|------|
| 2005~2006 | `M_SLP_DR` | 수면 시간(시간, 직접 기록) — 계산 불필요 |
| 2007~2025 | `M_SLP_HR` + `M_WK_HR` | 취침시각 + 기상시각 → 차이 계산 |

→ **Loader 처리**: `M_SLP_DR` 존재 시 직접 사용, 없으면 시각 차이 계산

## 종단 분석 시 주의사항

1. **표본 수 변화**: 2005(75,066명) → 2025(54,170명) — 표본 크기 상이
2. **스트라타 변경**: 시도 재편에 따라 STRATA 수 변동 → 복합표본 통계량 연도 직접 비교 주의
3. **문항 변경**: 스트레스(M_STR) 척도가 연도별 문항 표현 소폭 변경될 수 있음
4. **신규 문항**: 약물 관련, 전자담배 등은 특정 연도부터 추가되어 전 기간 분석 불가
5. **가중치 재산출**: 각 연도 W값은 해당 연도 인구 기준, 연도 간 직접 합산 불가
